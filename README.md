# Kompi Samarth — Personal Portfolio & Engineering Archive

A cinematic, modern portfolio website showcasing systems engineering, applied artificial intelligence, numerical simulation, and product research. Built for **Kompi Samarth** (Computer Science, RVCE Bengaluru).

Inspired by the atmospheric aesthetic of *Dune*—obsidian space, spice orange, muted sand, and parchment—combined with modern developer-focused interactive ergonomics (floating glassmorphic pill dock, live Bengaluru IST telemetry, interactive technical telemetry drawers, and Web Audio API soundscapes).

---

## ✦ Core Features

- **Cinematic Dune Aesthetic & Editorial Typography**: High-contrast, minimal color palette (`#11100E` obsidian, `#D5B98D` dune sand, `#C86B32` spice orange, `#F1E6D0` parchment, `#78A6C8` muted blue) paired with Playfair Display, Geist, and JetBrains Mono.
- **Scroll-Driven Project Showcase (01 — 08)**:
  1. `01 · AI-Based Student Dropout Prediction System` (Scikit-learn, Random Forest, TreeSHAP)
  2. `02 · StayHub: Property Management System` (Java 17, Swing, OOP MVC)
  3. `03 · C-Based Real-Time AI System Monitoring Sidecar` (Pure C11, POSIX shared memory ring buffers, native ONNX Runtime C API)
  4. `04 · Nanotechnology-Based Smart Coatings for Corrosion Protection` (Materials science, self-healing microcapsules, EIS impedance)
  5. `05 · S-Shape Air Intake Optimization for a Twin-Compressor Jet Engine` (Aerospace CFD, Mach 0.78 total pressure recovery)
  6. `06 · Hostel Mess Nutrition, Dining and Planning Survey` (Human-centred design, N=420 survey analytics, Poisson queue modeling)
  7. `07 · AI-Based News Aggregator with Fake News Detection & Bias Analysis` (NLP transformers, stylometric entropy)
  8. `08 · Driver Drowsiness and Alcohol Detection System` (Computer vision, EAR/PERCLOS facial landmark mesh, MQ-3 sensors)
- **Interactive Technical Spec & Telemetry Drawer**: Click *"Inspect Telemetry & Specs ⚡"* on any project to inspect live benchmark cards, architectural formulations, and copyable source code snippets.
- **Discipline Filter Toolbar**: Instant filtering across *Systems & Low-Level*, *Applied AI & ML*, *Engineering & Simulation*, and *Product & Research*.
- **Tactile Web Audio Engine**: Always-active tactile feedback clicks on interactive elements, dual-tone sci-fi chimes, and a procedural mild *Dune* ambient soundscape (55 Hz sub-drone, resonant modal spice pad, and slow desert wind swells).
- **Keyboard Navigation**: Press <kbd>J</kbd> or <kbd>↓</kbd> to cycle forward through projects, and <kbd>K</kbd> or <kbd>↑</kbd> to cycle back.
- **Dynamic Ambient Sunlight**: Responsive background warmth shifts dynamically from midday sand to twilight spice orange and deep nightfall as you scroll.
- **Mobile Thumb Dock**: Responsive design with a dedicated floating thumb dock for mobile viewports (`<= 680px`).

---

## ✦ Tech Stack

- **Markup & Layout**: Semantic HTML5, CSS3 Custom Properties, Modern Flexbox & CSS Grid
- **Typography**: Playfair Display, Geist, Inter, JetBrains Mono
- **Audio**: Web Audio API (procedural synthesis, zero audio file dependencies)
- **Zero Heavy Framework Dependencies**: Pure Vanilla JavaScript (ES6+), clean, performant, and dependency-free.

## ✦ Getting Started Locally

Clone the repository and serve with any local HTTP server:

```bash
# Clone the repository
git clone https://github.com/kompisamarth/portfolio.git

# Navigate to the folder
cd portfolio

# Run a local web server (Python 3)
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
